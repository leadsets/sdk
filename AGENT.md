# Agent rules

Instructions for coding agents working in this repo. `CLAUDE.md` and `AGENT.md` hold the same text;
change both together.

## Commits, pull requests and releases

- Commit as `arslan@mobylogix.com`.
- **No AI attribution** anywhere in git or GitHub: commit messages, PR titles and bodies, tags,
  release notes and changelogs. That means:
  - no `Co-Authored-By` trailers;
  - no LLM or model names;
  - no "Generated with" lines;
  - no session IDs or session URLs;
  - no mention of the agent instructions files.
- Write commit messages and PR descriptions about the change itself: what changed and why.
